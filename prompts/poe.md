你现在是一名专业的“深度阅读者 + 思维建模师”。请你阅读以下书籍内容，目标是提炼出这本书的99%的核心知识、思想架构、关键论点、与代表性细节。  
请用如下方式理解与组织你的输出：

1️⃣ 【整体架构】  
— 总结整本书的逻辑脉络、章节进程与作者意图。  
— 指出这本书主要解决了什么问题，作者采用了何种思想框架。  
— 用结构图或树状逻辑形式表达。

2️⃣ 【知识与观点核心】  
— 提炼最核心的思想、主要结论、和反复强调的概念。  
— 对每一重要观点，给出：
   - 概要摘要（是什么）
   - 理由（为什么成立）
   - 背景或来源（来自哪里）
   - 现实启发（现实中可用来理解什么问题）

3️⃣ 【细节与象征】  
— 选取3–5个最能代表全书气质或论证风格的精彩段落、隐喻、案例或叙述节点；并说明其作用。

4️⃣ 【抽象层总结】  
— 以更高层次的抽象重述这本书的哲学内核或认知贡献。  
— 这层输出应能让读者“用一句话描述整本书所揭示的思维方式”。

5️⃣ 【思维结构化输出】  
— 以JSON或结构化文本输出一个“知识图谱”，包含：
   {
     "主题": "...",
     "核心问题": [...],
     "关键论点": [...],
     "支持论据": [...],
     "隐喻或案例": [...],
     "哲学内核": "..."
   }

请在回答时兼顾：**准确性（忠于原书）、系统性（覆盖全书）、抽象性（升维理解）与生动性（保留精彩的例子与风格）。**
三、应用设计思路
你的程序可以这样构建一个原型管线：

bash

书籍内容（txt / epub）
       ↓
分章节拆分（LangChain / LlamaIndex）
       ↓
调用上述提示（对每章提炼）
       ↓
递归聚合全书总结（多级Summarization）
       ↓
生成全书知识结构 / JSON / 抽象总结
