# 0176 为 library 阅读分区补降级提示和空态规则

## 这次改动做了什么

这一步继续执行 `03-01`，但只收空态和降级语义。

我没有再增加新 section，而是补了一个轻量的 `readingWorkflowNotice`：

- 当没有进行中的书，但还有最近阅读时
- 当书库里只有刚导入、未开始的书时
- 当最近没有在读书，主要都是已读完的书时

library 顶部现在会给出不同提示，而不是简单地“什么都没有”。

## 为什么这一步重要

如果 continue reading 规则收紧后，没有补对应降级提示，就会出现一个新问题：

- section 逻辑是对的
- 但用户会以为“是不是数据丢了”

尤其是这几种场景很容易让人困惑：

1. 最近看过书，但当前没有在读
2. 刚导入很多书，但一本都还没打开
3. 最近主要是把书读完，而不是继续推进

这三种情况都不是异常，但如果不解释，看上去就像 UI 漏了一块。

## 你可以学到的工程知识

### 1. 收紧规则之后，通常要补“为什么现在为空”的解释

很多界面在第一版时规则很宽，所以“总有东西显示”。

一旦你把规则做正确：

- 过滤更严格
- section 更明确
- 结果就可能更容易为空

这时不能只说“空了”，而要告诉用户：

- 为什么空
- 接下来什么操作会让它重新出现

### 2. 空态不一定要是一个大块 empty state

这次没有把它做成一个大面板，而是用了更轻的 workflow note。

原因是：

- 用户并不是没有书
- 只是当前没有满足某个分区规则的书

这种时候用轻提示比用“整个区域空了”的重空态更合适。
