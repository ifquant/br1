# 0724 - 短暂标出页内跳转落点

## 背景

`S2-R04C6` 对应 Readest `dbe0dae0a`，不含 Foliate gitlink 变更。
脚注不能预览、或者本来就是普通页内链接时，跳转成功仍可能让读者
找不到目标。本次沿现有导航入口增加短暂的位置提示。

## 改动概览

- 普通内部链接、数字脚注回退、显式预览的正文跳转共用宿主入口。
  导航仍由 Foliate 执行一次，提示使用它返回的章节和锚点。
- 重用 Overlayer 的绘图函数，把临时图形挂到已有 SVG 上，4 秒后
  删除；不修改原文、用户选区，也不把提示存成批注。
- 新导航意图使旧请求失效；重新定位、布局变化、换书和卸载清理图形。
  原生 renderer 的事件原因用于区分自身定位与后续翻页/滚动。

## 关键知识

1. `preventDefault()` 必须在异步等待之前完成。否则依赖库可能已把
   默认跳转排入后续任务，宿主再调用一次导航就会产生重复跳转。
2. SVG 的 `pointer-events: none` 不代表批注命中逻辑不会读取它。
   Foliate 还维护自己的命中表；临时提示不进入该表，避免改变鼠标指针
   或遮挡真实批注。清理只移除自己的图形，不清空搜索或批注。

## 验证

- C6 定向浏览器测试：3/3 PASS；脚注与原文排版回归：18/18 PASS；
  旧脚注、安全清理和 TXT 回归：4/4 PASS，共 22 个不重复用例。
- `pnpm check`：0 errors、0 warnings；`pnpm build` 与
  `git diff --check`：PASS。
- Terra high 独立任务审查、Astra high 最终静态审查：PASS。

测试以 Foliate 完成原生导航后的 DOM 为基线，因为依赖库本身会设置
目标的焦点属性。落点验证比较实际图片与单个 SVG 图形的重叠，避免
把外层图形包围盒误当成被标记内容，也避免跨 iframe 的类型判断误差。
