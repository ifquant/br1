# 0720 - 让俄语短词与后文一起换行

## 背景

Readest `370a51662` 用不换行空格避免俄语短词孤立在行尾。本次处理
`S2-R04C2`，复用 C1 的正文处理入口，不引入新的转换框架。
该上游提交没有修改 foliate-js gitlink，本次也不修改兄弟渲染库。

## 改动概览

- 沿用 `pickText` 选择书籍元数据中的第一个非空语言值，去除首尾空白、
  转小写并取连字符前的主语言；仅 `ru` 启用。`rus`、`ru_RU` 不做别名推断。
- 使用上游完整的 50 个功能词和一至两个西里尔字符的短词规则。
  只有后接单个普通空格，再接西里尔字符或 Unicode 数字时才替换。
- 在已有的安全正文节点遍历中处理，不跨节点连接；代码、属性、样式、
  SVG、MathML 等内容沿用 C1 排除规则，原书文件不改写。
- XHTML 输出使用 `&#160;`，避免没有 DTD 时 `&nbsp;` 无法解析；
  HTML 输出仍使用已有的命名实体，不修改 MIME 或安全清洗规则。

## 关键知识

1. JavaScript 的 `\b` 主要围绕 ASCII 单词字符工作，不适合作为西里尔文
   的通用词边界。这里使用 Unicode 字母属性，并捕获、保留非字母边界。
   因为一次匹配会消耗下一个词所需的边界，需要重复替换直到稳定。
2. 普通空格和 NBSP 都占一个 UTF-16 编码单元。替换不会移动已有文本偏移，
   但序列化成实体后，HTML 字符串长度会变化；应检查解析后的文本节点、
   实际章节和选区，而不是比较 HTML 字符串长度来宣称批注兼容。
