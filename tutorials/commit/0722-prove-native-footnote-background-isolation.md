# 0722 - 验证原生脚注弹窗的背景隔离

## 背景

`S2-R04C4` 检查 Readest `1d8ed3fc9`、`d6e981e56` 和前者的
嵌套 foliate-js 变更。上游使用独立分页器显示脚注，br1 则提取并
清洗内容，再交给已有 Svelte 弹窗；不能只按补丁形状判断缺口。

## 改动概览

- 沿现有 EPUB 测试入口验证书籍背景、边框和尺寸不会进入原生弹窗。
- 不新增分页器、背景开关、自定义字体设施或正文脚注隐藏规则。
- 单独记录正文脚注显示策略的缺口，避免把“不适用”写成全部对齐。
- 嵌套 `af4f384b7` 还改变滚动模式的水平页边距变量。该义务转入已有
  `S2-U01B`，因此外层 `1d8ed3fc9` 仍是 `partial`，不因弹窗验证而全部关闭。

## 关键知识

1. CSS 的 `@namespace` 必须先于普通样式和 `@font-face`。但 br1
   当前没有把这两类规则拼到一起，也没有依赖命名空间的隐藏选择器；
   为迁移修复而先引入其故障前提，只会增加不必要的功能和维护成本。
2. 弹窗清洗克隆内容，不改原书 DOM。剥离样式可以隔离作者的排版，
   却不等于应该隐藏原文：未被识别为脚注的链接仍可能导航到该位置。

## 验证

- 首轮 Playwright：12/13 PASS，新用例把桌面宽度上限误用于窄窗口。
  修正后第二轮仍为 12/13：额外的完整视口断言在 1280×720 桌面失败
  （弹窗底部 763.5px），但阅读区域边界检查通过。最终限定为真实阅读
  区域内、短文本弹窗高度不超过 300px，以及作者样式前后尺寸差异
  不超过 1px；不把可滚动整页的短高度适配混入本次背景隔离验收。
- `pnpm check`：PASS，0 errors / 0 warnings；`pnpm build`：PASS。
  后续只修改测试和文档，生产源码未变。
- `git diff --check`：PASS；678 条提交账本重新计数：PASS。
- 最终 `pnpm exec playwright test tests/e2e/footnote-compat.spec.ts tests/e2e/authored-text-compat.spec.ts --workers=1`：PASS，13/13。
  覆盖 1280px / 640px 窗口、同章与跨章脚注、真实加载图片、原文保持、
  干净预览结构、阅读区域边界及有无作者样式时的等尺寸呈现。
- 独立 Terra high 任务审查与 Astra high 最终审查：PASS。

## 未覆盖项

- 不宣称未调用的 Foliate 弹窗 API 已更新；主阅读器背景行为未改。
- 不宣称打包 Tauri、移动端设备或所有浏览器的渲染验收。
